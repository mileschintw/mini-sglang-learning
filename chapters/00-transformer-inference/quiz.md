# Ch0 Quiz 紀錄

## 第 1 輪（10/9）

| 題 | 結果 | 診斷 |
|---|---|---|
| Q0.1 | ❌ | **核心誤解**：把 Q→K→V 當成先後發生的三個階段（V 是「經過整個模型後」產生的）。實際上這三個向量是**同一個輸入**經過三個不同權重矩陣，**同時**算出來的。不知道 causal mask 是什麼。 |
| Q0.2 | 🟡 | (a) 大致正確。(b) 只答出「權重不變」這一個條件，少了第二個（跟 Q0.1 的 causal mask 有關）。(c) O(N^N) 不對，有 cache 時的 O(N) 對了一半。 |
| Q0.3 | 🟡 | residual 的直覺大致正確。RoPE 的作用對象答錯（少了一個）；它的主要目的是**編碼位置**，不是「放大 context window」。延長 context 是 RoPE scaling 這個衍生技巧做的事。 |
| Q0.4 | ❌ | 沒有算。結論「每個 token 佔用越多，能服務的使用者越少」方向正確。 |
| Q0.5 | ❌ | 不知道 |
| Q0.6 | ❌ | 不知道 |

**決定**：Ch0 不能跳過。講義要改寫成**從零開始的版本**，用一個極小的數值例子實際算一遍 attention，讀完後重考第 2 輪。

### 你的原始答案

- **Q0.1**：token 0 的 Q 是 0，接著該 token 為 K，經過整個模型後會產生 V。Q 是前面（0 到 i-1）的每一組 KV 對現在這組 KV 的影響力權重；K 是透過 Q 權重對前面的 V 加權計算完的新 K，並以此 K 為依據算出本次的 V。不知道 causal mask 是什麼。
- **Q0.2**：需要 0 到 t 個 token 的 KV。只要模型權重維持不變，就能直接沿用。沒有 cache 需要 O(N^N)，有的話會變成 O(N)。
- **Q0.3**：不知道。RoPE 加在 Q 上，用來放大 context window。Residual 是讓上一層的資料可以直接漏到下一層，讓運算時的上下文更完整。
- **Q0.4**：不知道，但每個 token 的 KV cache 佔用越多，能服務的用戶就越少。
- **Q0.5**：不知道。
- **Q0.6**：不知道。
